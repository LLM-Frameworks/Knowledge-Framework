# Roundtable

Multi-seat stress-test of one assignment. Moderator keeps the stake; other seats are task-defined (Advocate/Red, Money/Engineer/QC, etc.).

## Quick use

1. Copy `task-template.md` → fill goal, constraints, defeat/success condition, cast.
2. Assign who plays which seat (optional note on the card). **Role ≠ model name.**
3. Send each AI: shared task + filled `seat-template.md` + transcript if any.
4. Run until a stop condition in `method.md`.
5. Steward holds, promotes, or kills the result.
