# Blog — A Stone's Throw

Method app for turning settled references and briefing fuel into published posts.

**Public name:** A Stone's Throw  
**Status:** Nominated (Developer until audited)

## Pipeline

```
Briefing → Topics / References → Blog posts
                              → Comment / debate aid (sibling app)
                              → (later) Courses
```

## Inputs

- **References** — settled public positions
- **Briefing** output — when automated or saved files exist
- **Settings/seeds.md** — personal idea inventory by topic
- **Settings/style-anchor.md** — optional voice samples / blacklist

## Quality gate

- Every atomic claim tagged; receipt = source + warrant
- Other side steel-manned before rebuttal
- Memory-sourced claims capped at [Likely] and admitted in prose
- Nothing publishes without the Steward’s explicit word

## Layout

| Path | Role |
|------|------|
| `framework.md` | Editorial standard, name, publish loop |
| `Settings/seeds.md` | Idea inventory by topic |
| `Settings/drafts/` | In-progress writing (personal) |
| `Settings/next.md` | Optional single “writing this next” pointer |

Published posts are not stored inside this app folder.
