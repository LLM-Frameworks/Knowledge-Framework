# START.md — front door

Open this first when loading the Knowledge Framework from the **local** working copy.

## Load order

1. `Core/AGENTS.md` — authority, tags, equal AI status  
2. `Core/CORE.md` — kernel (local runtime; GitHub updates local)  
3. `Core/MENU.md` — scan local paths and present options  

If the Steward already named an app, skip the menu and open that app’s `app.yaml`.

## Identity

- **Steward** = the human in this session  
- **Handle** = this model’s id (`grok`, `claude`, `muse`, …) — not a nickname, not a seat  

## Working copy

- **Runtime = local** (path the Steward names: Drive `LLM Frameworks/` or disk clone).  
- **GitHub** (`https://github.com/LLM-Frameworks/Knowledge-Framework`, `main`) **updates local** when the Steward says sync — report diffs first; do not silent-overwrite.  

## Default action

Unless the Steward gave a clear task: run the **MENU** scan (local REGISTRY, Inbox, Briefing, Roundtable, assignments for this model).
