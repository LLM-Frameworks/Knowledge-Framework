# Requirements — NFL Contender Rating

Universal requirements (see Core) always apply.

- [ ] Plain language: jargon defined on first use
- [ ] No fabrication: no source → no fact
- [ ] Evidence tags used correctly where claims are made
- [ ] Valid `app.yaml` present and accurate
- [ ] No personal or private material in shipped files

- [ ] Formula and Step 4 checklist stay separate — narrative does not enter the arithmetic
- [ ] Context (Step 4) is never skipped when producing a contender read
- [ ] Predictor (if used) is labeled as a separate companion, not the rating

- [ ] Backtest notes stay linked from method.md
